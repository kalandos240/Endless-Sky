# Endless Sky — Android / RuStore

Перенос [Endless Sky](https://github.com/endless-sky/endless-sky) на Android для последующего выпуска в RuStore.

**Статус: тестовый APK 0.3 с сенсорным управлением, переносом пилотов и откатом восстановления успешно собран в GitHub Actions.** Проверены нативные библиотеки arm64, ресурсы, SDL/JNI-функции и debug-подпись. Файловая логика копий и очистки проверена автоматически; запуск, file picker и поведение после импорта на физическом устройстве пока не проверены.

## Подготовка и сборка

Нужны Python 3.10+, Git, JDK 17, Android SDK Platform 35, Build Tools 35.0.0, NDK 28.2.13676358 и CMake 3.31.6. На Linux для зависимостей также нужны C/C++ compiler, autoconf, automake, libtool, pkg-config и nasm.

```sh
python3 tools/prepare_android.py
cd android
./gradlew assembleDebug
```

Укажите SDK через `ANDROID_HOME` или `android/local.properties` (`sdk.dir=...`). Первая сборка скачивает Gradle и исходники нативных зависимостей; потребуются интернет, несколько гигабайт диска и время на компиляцию. Рабочая конфигурация рассчитана на Linux; другие хосты не проверены.

Результат при успешной сборке: `android/app/build/outputs/apk/debug/app-debug.apk`. Это debug-пакет с тестовой подписью, не пакет для публикации. В CI workflow **Android debug APK** также собирает и прикладывает APK как artifact; наличие workflow само по себе не означает успешную сборку.

Начальная цель: **arm64-v8a, Android 8.0+ (API 26), OpenGL ES 3.0**. Текущий development applicationId — `io.github.kalandos240.endlesssky`, у debug-сборки суффикс `.debug`. Постоянный идентификатор нужно подтвердить до первого выпуска.

Релизная сборка с постоянным ключом: [инструкция](docs/RELEASE.md). Без параметров подписи `assembleRelease` и `bundleRelease` завершаются ошибкой; debug-сборка работает без них.

## Как устроен порт

- `upstream-revision.txt` закрепляет commit игры; `patches/` содержит изменения её CMake и путей ресурсов.
- `tools/dependencies.json` закрепляет SDL2 и vcpkg. Java-код SDLActivity берётся из той же SDL **2.32.10**, что и нативная библиотека; версия дополнительно закреплена в vcpkg manifest.
- `android/native/` подключает игру как `libmain.so` через NDK и vcpkg. SDL2 и OpenAL собираются shared, остальные зависимости — static. Включён AVIF decoder dav1d.
- `LauncherActivity` устанавливает ресурсы в фоновом потоке с прогрессом и повторной попыткой. Запуск SDL происходит после установки.
- `ResourceInstaller` проверяет SHA-256 манифеста и каждого файла, отклоняет лишние/повторные записи и выход за каталог, проверяет свободное место. Новая версия публикуется отдельным каталогом после полной распаковки. Незавершённая установка не получает маркер готовности.
- `GameActivity` передаёт игре `--resources <files>/resources/<content-id>` и `--config <files>/config`. Сохранения и настройки не затрагиваются установщиком. Старые версии ресурсов удаляются после проверки и публикации новой. Незавершённые распаковки очищаются до проверки свободного места; неизвестные каталоги и текущая версия остаются на месте.
- Ресурсы, исходные лицензионные материалы игры и значок готовятся локально. Уведомления SDL и установленных vcpkg-зависимостей включаются в APK assets.

Исходники и генерируемые файлы находятся в `build/`, не коммитятся. Скрипты не перезаписывают checkout другой версии. После изменения игровых ресурсов можно пересобрать только assets:

```sh
python3 tools/prepare_android.py --assets-only
```

## Сенсорное управление (0.2)

Панель появляется только в полёте. Слева — тяга, повороты и реверс; справа — основное/дополнительное оружие, форсаж и выбор оружия. Внизу по центру — выбор цели/ближайшего врага, абордаж, связь, посадка и прыжок. Сверху — карта, пилот, пауза и меню.

Можно одновременно удерживать несколько кнопок. Короткие нажатия сохраняются до игрового кадра. Кнопки вызывают игровые команды напрямую, независимо от раскладки клавиатуры; физическая клавиатура продолжает работать отдельно. Панель можно скрыть кнопкой «Скрыть» и вернуть кнопкой «Кнопки»; выбор запоминается.

При открытии игровых окон панель скрывается. При потере фокуса, сворачивании, повороте экрана или скрытии панели все удерживаемые команды отпускаются. Кнопки — отдельные дочерние View поверхности SDL, чтобы касания игровой области и нескольких кнопок могли обрабатываться раздельно. Android Back открывает меню в полёте и передаёт Escape в других игровых окнах; открытая экранная клавиатура сохраняет стандартную обработку Back.

Логика указателей, коротких нажатий, отмены и границы Java/JNI покрыта тестами. Реальные жесты, удобство расположения и работу на устройстве ещё нужно проверить. Аналоговый джойстик и настройка расположения кнопок пока не добавлены. [Сценарии проверки на устройстве](docs/DEVICE_TESTS.md).

Сборки CI используют debug-подпись. Тестовый ключ кешируется для повторных сборок, но кеш может быть удалён; совместимость подписей с предыдущими тестовыми APK не гарантируется. Перед переустановкой сохраняйте файлы пилота. Для будущего выпуска RuStore нужен постоянный ключ подписи вне репозитория.

## Пилоты и обновления (0.3)

При запуске доступен экран «Играть», «Сохранить копию пилотов и настроек» и «Восстановить из копии». Копия выбирается через системный выбор файла Android; разрешение на доступ ко всей памяти не требуется. Пока игра работает, повторный запуск приложения возвращает в игру, не открывая управление сохранениями.

В архив входят `saves/*.txt`, `pilots/*.txt`, настройки клавиш/игры и глобальный прогресс/статистика. Плагины, журнал ошибок и `recent.txt` с абсолютным путём не экспортируются. Копию нужно сохранить вне приложения; после восстановления пилот выбирается в игровом меню. Архивы этого формата создаются самим приложением; произвольный ZIP с настольными сохранениями пока не поддерживается.

Импорт сначала проверяет манифест, пути, размеры и SHA-256 всех файлов и распаковывает их отдельно. Затем показывает число профилей/сохранений и файлов и запрашивает подтверждение. До подтверждения текущие пилоты не изменяются. При подтверждении сохраняется предыдущий каталог настроек; кнопка «Вернуть предыдущие сохранения» позволяет откатиться. Локальные плагины при восстановлении сохраняются. Поддерживается один предыдущий снимок; следующее подтверждённое восстановление заменяет его.

При прерывании процесса между переименованиями конфигурация восстанавливается при следующем запуске. Старый игровой процесс завершается только после остановки SDL и завершения native main, чтобы статические кеши игры не переиспользовались после импорта. Сворачивание игры сохраняет прежнее поведение паузы.

Пределы переносимого архива: до 10 000 файлов, до 64 МиБ на файл и до 512 МиБ суммарно. При импорте может дополнительно понадобиться место на временную копию текущей конфигурации, включая локальные плагины. Копия не содержит игровые ресурсы; ресурсы устанавливаются отдельно.

## Проверки

```sh
python3 -m unittest discover -s tests -v
python3 tests/make_installer_fixtures.py
mkdir -p build/java-tests
javac -Xlint:all -Werror -d build/java-tests android/app/src/main/java/io/github/kalandos240/endlesssky/ResourceInstaller.java tests/java/ResourceInstallerTest.java
java -cp build/java-tests io.github.kalandos240.endlesssky.ResourceInstallerTest build/installer-fixtures
mkdir -p build/backup-tests
javac -Xlint:all -Werror -d build/java-tests android/app/src/main/java/io/github/kalandos240/endlesssky/SaveBackup.java tests/java/SaveBackupTest.java
java -cp build/java-tests io.github.kalandos240.endlesssky.SaveBackupTest build/backup-tests
```

Проверены детерминированность ZIP и манифеста, применение upstream-патча, повторная установка, повреждённые/неполные/повторные/лишние ZIP-записи, недопустимые пути, нехватка места, прерывание и восстановление, сохранность файлов пилота. Полный пакет игры также установлен и проверен: 7402 файла, 403 688 392 байта. Java-код обеих Activity и официального SDL bridge скомпилирован против Android API 35 отдельно от Gradle (с временным `R` для проверки типов); это не заменяет сборку APK. Эти проверки запускаются также workflow **Port checks** (отдельная проверка типов Activity через SDK выполнялась локально; полный APK собран в CI).

После сборки можно отдельно проверить архитектуру нативных библиотек, наличие ресурсов и уведомлений:

```sh
python3 tools/check_apk.py android/app/build/outputs/apk/debug/app-debug.apk
```

Эта проверка, проверка debug-подписи и установка полного пакета ресурсов также входят в workflow сборки APK. Полная сборка прошла успешно: в APK найдены четыре AArch64-библиотеки; подпись APK Signature Scheme v2 проверена. Проходят 8 Python-тестов, 52 проверки Java-установщика и 51 проверка переносимых копий/отката, тест указателей Java и многопоточный тест состояния ввода C++.

## Реклама

Выбран Яндекс, запрошен интервал 150 секунд. Добавлена и покрыта тестами независимая политика планирования `AdSchedule`; к игровому lifecycle и SDK она пока не подключена. Настоящих объявлений в APK нет. Нужны ID блока РСЯ и разрешение вопроса совместимости лицензии SDK с GPL игры. [Статус и правила показа](docs/ADS.md).
