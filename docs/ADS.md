# Реклама в Android-порте

Текущий рабочий межстраничный блок: `R-M-20327075-1`.
Новая конфигурация: версия 0.4.1, versionCode 5. Старый APK 0.4.0 не изменяется.

## Места показа

Возможность показа появляется после нового входа:

- в главное игровое меню;
- в основное окно планеты после посадки;
- обратно в основное окно планеты после закрытия торговли, банка, космопорта,
  найма, магазина кораблей, снаряжения, заданий или миссионного диалога.

Нужны 150 секунд активного времени с начала сессии/предыдущего показа и готовое
объявление. Переход отслеживает game thread после шага интерфейса; Java ждёт,
пока тот же экран будет открыт не меньше 750 мс, и повторно проверяет его перед
показом. Если промежуточный диалог закрывает сцену, возможность отменяется.
В полёте, бою, на карте, в диалогах, при установке ресурсов и переносе сохранений
показ не предлагается. Реклама при запуске, баннеры и rewarded не добавлены:
имеющийся ID относится к interstitial, для других форматов нужны отдельные блоки.

Время в фоне и в рекламе не входит в интервал. Пропущенные показы не
накапливаются; при отсутствии объявления игра продолжается. После ошибки показа
до следующей попытки нужно минимум 30 секунд активного времени. Возврат из
рекламной Activity/фона не создаёт повторный показ в том же окне.
Если реклама загрузилась позднее, она ждёт следующего перехода, а не появляется
внезапно на уже открытом экране. Бюджет времени пока не сохраняется между
перезапусками процесса.

## SDK, тесты и настройки

SDK Яндекса закреплён на 8.6.0; автоматическая инициализация выключена.
Отслеживание точного местоположения выключено. Перед первым запуском игры в
рекламной конфигурации показывается уведомление о SDK и выборе персонализации.
По умолчанию согласие не предоставлено; выбор сохраняется и передаётся SDK при
каждом запуске. Изменить его и открыть политику Яндекса можно через «О приложении».
Это не замена политике обработки данных и контактам конкретного издателя.

- Без `esAds`: SDK и рекламные разрешения не добавляются.
- `-PesAds=yandexTest`: демонстрационный блок; release запрещён.
- `-PesAds=yandex`: release использует рабочий ID, debug всегда использует
  `demo-interstitial-yandex`.

Рабочий блок должен относиться к нужному приложению и быть разрешён РСЯ.
Активность блока в кабинете сама по себе не доказывает наличие рекламного fill.

Проверяются 150-секундный интервал, фон, повторы, ошибки, стабильность переходов,
многопоточная передача места показа. Release CI дополнительно проверяет реальный
ID в DEX, присутствие SDK и уведомления, версию и отсутствие debug-флага.
Реальные жесты, возврат из рекламы, звук и показы на физическом устройстве ещё
нужно проверить по [сценариям](DEVICE_TESTS.md).

[Проверка лицензий](LICENSE_REVIEW.md) остаётся в силе. Включение рабочего ID и
успешная компиляция не являются юридическим разрешением или одобрением RuStore.
