# Реклама: подготовка интеграции РСЯ

Запрошен интервал 2 минуты 30 секунд; выбран Яндекс.

**Текущий статус: настоящие объявления не подключены.** SDK, ID блока, сетевые
разрешения и рекламные экраны в APK пока отсутствуют. `AdSchedule` — отдельно
тестируемая политика, ещё не подключённая к Activity. Она не имитирует рекламу.

## Политика показа

- Первый показ возможен после 150 секунд активного использования в рамках сессии.
- Показ только в явной естественной паузе: переходе в меню или завершении игрового
  действия. Истечение таймера во время боя откладывает возможность показа.
- Сворачивание приложения и просмотр объявления не засчитываются в интервал.
- При отсутствии готового объявления игра продолжается. Пропущенные возможности
  не накапливаются; несколько объявлений подряд не показываются.
- После успешного показа и закрытия начинается новый интервал 150 секунд.
- При ошибке показа — не менее 30 секунд активного времени до повторной попытки.
- Старые и повторные callbacks не должны закрывать новое объявление.

Для Android-адаптера нужен монотонный `SystemClock.elapsedRealtime`, вызовы на UI
потоке и корректные уведомления о фоне, показе и закрытии. Перед открытием рекламы
нужно отпускать сенсорные команды и приостанавливать игровой цикл/звук; после
закрытия — восстанавливать lifecycle SDL. Булево `nativeIsInFlight == false` само
по себе не означает безопасное место: там могут быть загрузка, ввод имени пилота
или файловая операция. Нужен сигнал конкретного перехода, а не периодический
показ поверх любого экрана. Сохранение бюджета между перезапусками пока не реализовано.

## Что требуется для настоящей рекламы

1. ID interstitial-блока из аккаунта РСЯ. Это идентификатор размещения, не пароль
   аккаунта; токены и пароли передавать в чат не нужно.
2. Подтверждение условий распространения комбинированного APK. Код игры GPL-3.0-or-later;
   SDK Яндекса использует собственное лицензионное соглашение. Совместимость не
   установлена. Наличие публичных примеров SDK не делает сам SDK GPL-совместимым.
   Исключение к лицензии чужого кода нельзя выдать от имени владельца этого порта.
3. После разрешения вопроса лицензии: SDK-адаптер, тестовый блок до включения боевого,
   обработка жизненного цикла, необходимые раскрытия о данных и проверка реального
   устройства, включая offline, возврат из рекламы и обновление APK.
