# Проверка GPL и Yandex Mobile Ads SDK

Проверено 31 октября 2026. Область проверки: объединение кода Endless Sky и
Yandex Mobile Ads SDK в текущей Android-архитектуре. Это анализ опубликованных
условий, а не юридическое заключение или полный аудит всех зависимостей и ресурсов.

## Результат

Публикация APK, объединяющего игру и SDK, не получает разрешения из проверенных
публичных условий: выявлен лицензионный конфликт. Объявлять эту конфигурацию
совместимой с GPL нельзя без дополнительных прав или подтверждённых иных условий.
Обычная сборка без SDK не имеет именно этого конфликта; её остальные обязательства
по лицензиям сохраняются.

## Основания

| Компонент | Проверенные условия | Значение для порта |
| --- | --- | --- |
| Endless Sky, commit abb41b23eb4accf207714003dc41ff640a2ce61a | copyright: GPL-3+; заголовок source/main.cpp: GPL версии 3 или более поздней | Код порта с игрой должен распространяться с соблюдением GPL |
| GPLv3, разделы 1, 5(c), 6, 10, 12 | Лицензирование объединённой работы, соответствующий исходный код, запрет дополнительных ограничений и правило несовместимых обязательств | Публикация исходников только нашего адаптера недостаточна для закрытого компонента объединённой программы |
| Публичная лицензия Mobile Ads SDK, пункты 3.1–3.3 | Ограниченное непередаваемое право использования; ограничение самостоятельного распространения SDK; разрешение распространения созданного с ним ПО с указанием SDK | Пункт 3.3 разрешает приложения с SDK, но не предоставляет пользователям права на SDK в объёме GPL |
| Наша интеграция | Java-адаптер напрямую импортирует SDK и через Activity/JNI связан с игрой | Для оценки рассматривается объединённая программа, а не случайное соседство независимых файлов |

SDK — прикладная зависимость, которую мы добавляем сами. Оснований считать его
системной библиотекой Android по исключению GPL не найдено. Раздельные Java/C++
файлы, JNI, динамическая загрузка, один дополнительный адаптер или наличие
исходников примеров сами по себе проблему не решают. Это вывод из архитектуры
порта и разъяснений GNU о связывании, не установленное судом решение.

В проверенных README, copyright, license.txt и заголовке main.cpp закреплённой
версии игры исключение для закрытого рекламного SDK не обнаружено. Это не
утверждение, что отдельно выданных разрешений не существует.

## Ограничение проверки условий Яндекса

Публичный LICENSE.txt репозитория SDK указывает на
https://legal.yandex.com/partner_ch/ . Этот адрес не удалось прочитать через
доступный веб-инструмент. Отдельно прочитана русская публичная лицензия
mobileads_sdk_agreement; её пункт 1.1 предусматривает приоритет договора участия
в РСЯ при противоречиях, а пункт 1.3 допускает отдельное соглашение.
Договор конкретного аккаунта РСЯ и условия внутри Maven-артефакта 8.6.0 здесь
не проверены. Поэтому нет оснований выдавать окончательное разрешение на выпуск
на основании старой публичной страницы или лишь успешной компиляции SDK.

## Как устранить препятствие

1. Выпустить версию без SDK Яндекса с выполнением GPL и лицензий ресурсов.
2. Либо получить достаточные дополнительные права: GPL-совместимые условия
   на SDK от Яндекса или разрешение на такое связывание от необходимых
   правообладателей GPL-кода и проверить остальные зависимости.
   Письмо Яндекса, просто разрешающее рекламировать приложение, прав на чужой
   GPL-код не добавляет.
3. Альтернатива для монетизации — прямое спонсорство без закрытого SDK;
   конкретную реализацию и требования к рекламным материалам нужно проверить отдельно.

GPL допускает коммерческое распространение. Проблема здесь в правах на
объединённый код, а не в заработке как таковом. Менять лицензию чужой игры
или самостоятельно дописывать исключение от имени её авторов нельзя.
